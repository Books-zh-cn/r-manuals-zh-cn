# r-manuals-zh-cn

## Description

Try to translate R manuals into Simplified Chinese.

-   **Original Book**: [r-manuals](https://cran.r-project.org/manuals.html)

-   **Translation Book**: [r-manuals-zh-cn](https://books-zh-cn.github.io/r-manuals-zh-cn/)
